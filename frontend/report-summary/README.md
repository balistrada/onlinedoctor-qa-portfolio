# Report-Summary (React / Jest)

Dieses Verzeichnis ist ein **lokales Beispiel**, kein Teil von veryops.

Die Komponente rendert eine Release-Empfehlung, die das Python-Reporting
bereits getroffen hat (`GO`, `CONDITIONAL`, `NO-GO`, `INCOMPLETE`). Sie holt
keine Daten und kennt die Website nicht. Sie zeigt nur, dass ein kleiner
React-Baustein mit Jest geprüft wird, weil der Stack der Stelle React und
Jest nennt.

```bash
npm ci
npm test
```
